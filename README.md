## 📋 Project Information
**Purpose:** 
MalwareLens A web-based static malware analysis platform built with Flask.

Upload a suspicious file, get a detailed report with file hashes, a risk score and risk level, and a visual graph, all without executing the file. Teams can also share verdicts, track hashes on a watchlist, and receive alerts.

Safety note: MalwareLens is built for education and defensive analysis. Run it on an isolated machine or VM, and never open or execute the samples you upload.
**Main Features:**
Analysis

Upload a file and receive an analysis report (up to 100 MB per upload)

Cryptographic file hashes (including SHA-256)

Risk score and risk level with a color-coded verdict

Interactive graph visualization of the results

Windows executable (PE) inspection using pefile

Saved report history for each user, plus downloadable reports

Supported file types

exe, dll, bin, scr, msi, bat, cmd, vbs, js, ps1, pdf, doc/docx, xls/xlsx, ppt/pptx, zip, rar, 7z, jar, class, apk, dex, elf, so, wasm, img, iso, txt

Collaboration

Cloud Sandbox communities: create or join teams, share analysis verdicts, and flag verdicts that look unreliable

Live feed and alerts: global activity feed, personal alerts, and a weekly digest

Hash watchlist: add file hashes (SHA-256) to a personal watchlist

Utilities and administration

Encryption tool: encrypt and decrypt files with a password using AES-256-GCM

Dashboard with personal stats and recent analyses

Admin panel to manage users, reports and support tickets, and to test email delivery

Settings: light/dark theme and profile picture

Contact page for support tickets

Security measures

CSRF protection on all state-changing forms

Security headers: Content-Security-Policy, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, and HSTS over HTTPS
